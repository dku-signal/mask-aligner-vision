# 모터 수동 조작 패널

`firmware/mega_all_control`(Mega_All_Control.ino 수정본)을 올린 Arduino Mega를 브라우저 버튼으로 움직이는 도구입니다. 정렬 알고리즘 없이 **모터·서보·전자석만** 시험할 때 씁니다.

## 실행

```bash
pip install -r requirements.txt
python tools/motor_panel.py              # 아두이노 포트 자동 선택, 카메라 0 1 2 표시
python tools/motor_panel.py --mock       # 보드 없이 화면만 시험
python tools/motor_panel.py --cameras    # 카메라 없이
```

브라우저에서 `http://127.0.0.1:8790` 이 열립니다. macOS는 터미널에 카메라 권한이 있어야 카메라 화면이 나옵니다.

## 안전 동작

- 이동 버튼은 **누르고 있는 동안만** 움직입니다. 손을 떼면 `X`(정지)를 보냅니다.
- 브라우저 신호가 0.5초 끊기거나 창을 벗어나면 서버가 자동으로 `X`를 보냅니다.
- Space / Esc = 전체 정지. **서보는 전체 정지로 멈추지 않으므로** T 또는 t로 멈춥니다.
- 리밋 스위치가 없으므로 처음에는 짧게 눌러 방향을 확인하세요.

## 명령표

| 버튼 | 대상 | 핀 |
|---|---|---|
| F / B | 정렬 X | STEP 48, DIR 49 |
| f / b | 정렬 Y | STEP 22, DIR 23 |
| Q / W | 이송 레일 1 | STEP 52, DIR 53 |
| E / R | 이송 레일 2 | STEP 26, DIR 27 |
| **J / H** | **이송 레일 1+2 동시** (같은 펄스) | 위 두 레일 |
| u / d, O / P, K / L | Z1, Z2, Z3 (DC) | 2/3, 34/35, 38/39 |
| G / T | θ 서보 회전 / 정지 | D5 |
| t | 프리얼라인 서보 정지 ↔ 회전 | D6 |
| M | 전자석 ON/OFF | D7 |
| X | 레일·Z 전체 정지 | — |

## 원본 Mega_All_Control.ino 대비 수정점

1. **연속회전 서보 부팅 정지** — 원본은 부팅 때 `write(0)`을 보내 연속회전 서보가 최고속으로 계속 돌았습니다. 부팅 시 두 서보 모두 90(정지)을 보냅니다.
2. **I2C 타임아웃 항상 켬** — Arduino AVR 코어 1.8.8에는 `WIRE_HAS_TIMEOUT` 매크로가 없어 원본의 `#if`가 꺼지고, ADS1115가 응답하지 않으면 `setup()`이 영원히 멈춰 어떤 명령도 받지 않았습니다. 타임아웃을 무조건 켜고, `ads.begin()` 전에 주소 응답을 확인합니다. 부팅이 끝나면 `READY`를 출력합니다.
3. **이송 레일 동시 구동 J/H 추가** — 레일 1·2에 같은 STEP 펄스를 동시에 냅니다. 양쪽 모터가 반대로 설치돼 있으면 `RAIL2_PAIR_INVERT`를 `true`로 바꿉니다.

## 알려진 점

- 2026-11-11 실장비 확인: 레일 1(Q/W)이 한 방향으로만 움직임. 펌웨어는 DIR 핀을 LOW/HIGH로 바꾸므로 DIR 배선(DIR+ 5V 공통, D53/D27 연결)을 확인해야 합니다.
- ADS1115 응답 없음 → 센서 값 대신 `ADS_ERROR`가 1초마다 나옵니다. 모터 조작에는 지장 없습니다.
- USB 2.0 허브 하나에 카메라 3대를 몰면 1대가 영상을 못 받습니다. 1대는 Mac 본체 포트에 따로 꽂으세요.
