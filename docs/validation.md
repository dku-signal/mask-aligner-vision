## B. X/Y/θ 실제 장비 재시험 · 2026-10-12

- 저장소 기준 커밋: `e18c525ea9380a6a77cf46640ef77ffec9adc357`.
- 실행: `mask_aligner_optimized_v4.py --camera 0 --detector opencv`.
- 사용자 확인: X/Y/θ 설치·고정·이동 여유, 카메라와 드라이버 설정 유지, 표식 배치 후 손을 뗀 상태.
- 결과: 23.47초 후 앱 `DONE`. 중심 간 거리 124.98 → 0.406 px.
- 명령: θ 2회, X/Y 7회, 종료 정지. 새 펌웨어 업로드·영점 초기화·제한 변경 없음.

[원시 결과 JSON](evidence/xy-theta-20261012.json)

### 각도의 구분

시작 각도는 +23.83°, **θ 단계 종료**의 저장값은 +3.82°입니다. X/Y 완료 시 `theta_error`는 null이었고, 이후 20회 상태 조회에서도 현재 각도는 null이었습니다. 중간 별도 조회에서는 현재 각도가 약 6.78°로 표시된 적도 있습니다. 현재 앱은 θ 단계를 마친 뒤 X/Y 완료 조건으로 종료하므로 **최종 각도 정확도는 추가 검증이 필요합니다**.

현재 θ 기준 4°는 설정값이지 달성 가능한 정밀도의 인증값이 아닙니다. 연속회전 서보의 시간 제어, 기계 응답, 영상 가림·검출 변동을 함께 검증해야 합니다.

### 영상과 원시 기록

- `docs/images/xy-theta-before.jpg`는 이 재시험의 시작 화면입니다.
- 같은 실행의 완료 직후 저장 이미지와 뒤의 프리뷰는 검은 안내 화면으로 남았습니다. 이를 정렬 후 실물 사진으로 사용하지 않습니다.
- README의 완료 사진은 사용자가 10월 13일 제공한 영상의 68초 지점에서 추출했습니다. 이 재시험의 전후 비교나 0.406 px의 사진 증거로 제시하지 않습니다.
- 첫 시도는 큰 영상 변화로 중단했고, 사용자가 손으로 표식을 옮겼다고 확인하여 교정 성능 평가에서 제외했습니다.

### 해석할 수 있는 것과 남은 것

영상상 중심 오차 감소와 실제 명령 실행, 앱의 완료 판정을 확인했습니다. 외부 계측 정답과의 비교, 반복 시행 통계, 최종 θ 정확도, μm 정렬 성능은 확인하지 않았습니다.
