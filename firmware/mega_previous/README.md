# mega_previous — 현재 장비 배선용 Mega 펌웨어 (2026-11-20)

하드웨어 팀의 `MEGA_PREVIOUS.ino`(11월 배선)를 바탕으로, 자동 시퀀스와 원상 복구에 필요한 명령을 추가했습니다. 실장비에 업로드해 `#PING → PONG`을 확인했습니다.

## 핀

| 축 | 수동 글자 | 핀 |
|---|---|---|
| 정밀 스테이지 X / Y | F·B / f·b | STEP 48 DIR 49 / STEP 22 DIR 23 |
| 이송 X 레일 / Y 레일 | Q·W / E·R | STEP 52 DIR 53 / STEP 26 DIR 27 |
| 이송 레일 1+2 동시 | J·H | 위 두 레일 |
| Z (기존) / Z 리니어 / Y 리니어 | u·d / P(↑)·O(↓) / L(넣기)·K(빼기) | 2·3 / 34·35 / 38·39 |
| 정밀 θ 서보 / 프리얼라인 서보 (연속회전) | T·G / t | D5 / D8 |
| 전자석 | M (토글) | D11 |
| 레이저 (ADS1115) | — | I2C D20·D21 |

## 명령

한 글자 명령은 기존과 같습니다(누르는 동안 움직이고 `X`로 정지).
`#`으로 시작하고 줄바꿈으로 끝나는 **줄 명령**은 보드가 스텝/시간을 직접 세어 스스로 멈추고 완료를 알립니다.

| 줄 명령 | 동작 | 응답 |
|---|---|---|
| `#<F/B/f/b/Q/W/E/R/J/H> <스텝>` | 레일을 정확히 그 스텝만큼 (약 10,000 스텝/초) | `DONE <글자> <스텝>` |
| `#<u/d/O/P/K/L> <ms>` | DC 축을 그 시간만큼 | `DONE <글자> <ms>` |
| `#t <ms> <+1/-1>` | 프리얼라인 서보 시간 회전 | `DONE t <ms>` |
| `#A <ms> <+1/-1>` | 정밀 θ 서보 시간 회전 | `DONE A <ms>` |
| `#M <0/1>` | 전자석 끄기/켜기 (절대값) | `DONE M <0/1>` |
| `#PING` | 연결 확인 | `PONG` |
| `X` | 모두 정지, 진행 중인 줄 명령 취소. 레일·서보가 중간에 멈췄으면 실제로 간 양을 먼저 알림 | `STOP <글자> <스텝/ms>` 후 `STOP` |

레일 이동과 서보 회전은 동시에 진행할 수 있습니다(프리얼라인: X 이송 중 회전).

## 원본 대비 수정

1. 연속회전 서보 두 개를 부팅 때 90(정지)으로 시작 — 원본은 0을 써서 전원을 켜면 계속 돌았음.
2. I2C 타임아웃을 항상 켬 — AVR 코어 1.8.8에서 `WIRE_HAS_TIMEOUT`가 없어 ADS1115 무응답 시 `setup()`이 멈췄음. 부팅 완료 시 `READY` 출력.
3. 이송 레일 1+2 동시 구동 `J`/`H`.
4. 위 줄 명령(유한 이동·시간 구동·서보 시간 회전·`DONE` 응답).

## 업로드

Arduino IDE 또는 `arduino-cli compile --fqbn arduino:avr:mega firmware/mega_previous` 후 업로드. 라이브러리: Servo, Adafruit ADS1X15.
`firmware/aligner_mega`는 11/5 배선 기준이라 현재 배선과 핀이 다릅니다.
